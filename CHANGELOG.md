# Changelog

Versioning: the minor number goes up by one with every published version (1.1, 1.2, 1.3...). The major number changes only when the owner decides a release is a major one.

## 1.5 (beta, 16 Oct 2026)

- Installed app on iPhone and iPad: one Save or send PDF button after the build, and one Save or send draft file item in the menu

## 1.4 (beta, 16 Oct 2026)

- Installed app on iPhone and iPad: Save PDF and Save draft file open the share sheet (choose Save to Files), since iOS opens downloads in a viewer with no way to save
- No automatic save after building in the installed iPhone app; the result box asks you to tap Save PDF
- Open in new tab hidden in the installed iPhone app

## 1.3 (beta, 16 Oct 2026)

- Help and feedback emails keep their line breaks in Gmail and other apps (standard CRLF line breaks)
- Numbered questions so the emails stay readable in any mail app

## 1.2 (beta, 16 Oct 2026)

- Send feedback button in the page footer and menu, opening a prefilled feedback email
- Last updated date shown beside the version in the footer and in help and feedback emails

## 1.1 (beta)

- Keep work on this device (optional, with PIN encryption), remember member details, auto-delete 30 days after the PDF is built
- Installable as an app on phones and desktops, works offline
- Snap a receipt from the bottom bar
- Gentler validation: required items are flagged as you go, Build shows everything outstanding
- Readable dates (Mon 02 Nov 26), phone fixes for zoom and date fields
- Choose PKI or hand signatures for the package
- Send draft file and Send PDF through the phone share sheet (phones only)
- Page footer with version number and a Help email; back-to-top button

## 1.0

- First release: itinerary, lodging, meals, expenses, receipts, DAOD 7000-1 statutory declarations, one PDF package
